# Ninja Survivor
### First project using Godot/C#

TOP-DOWN Arena Survival

GOALS: 
- Surive the waves of enemies and defeat the final boss.
- Collect items and buffs to help in your journey.
- Unlock new characters.

Controls:
- Movement -> A - W - S - D Keys
- Attack -> Left click for melee attack, Right click for ranged attack.
- Pause -> Use the ESCAPE Key to Pause the game at any time or to close Info Pop-ups

Feel free to contact in case of any bugs or feedback :)
