## Goals

- Survive waves of enemies and defeat the final boss  
- Collect items and buffs to help in your adventure  
- Unlock new characters  

---

## Controls

| Action   | Keys / Input |
|----------|--------------|
| Movement | `W` `A` `S` `D` |
| Attack (Melee) | Left click |
| Attack (Ranged) | Right click |
| Aim | Mouse |
| Pause / Close Info | `ESC` |
